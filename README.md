## 3. Компиляция и запуск

### Компиляция всех заданий:
```bash
cd ~/projects/"ООП Java"
javac -encoding UTF-8 *.java
```

### Запуск общего консольного навигатора:
В `Main.java` реализовано двухуровневое меню для выбора раздела (простые / сложные) и конкретной задачи:
```bash
java Main
```

### Запуск отдельного задания:
Каждая задача является полностью автономной со своим методом `main`:
```bash
# Примеры запуска простых задач:
java SimpleTask1_Temperature
java SimpleTask2_Triangle
java SimpleTask9_Calculator

# Примеры запуска сложных задач:
java Task1_Divisors
java Task2_GcdLcm
java Task10_Bank
```
